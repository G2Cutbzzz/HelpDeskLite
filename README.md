# HelpDesk Lite - Sistema de Gestión de Tickets

Aplicación web frontend para el registro, seguimiento y administración del ciclo de vida de incidencias técnicas en un entorno universitario. Desarrollada con estándares web modernos sin dependencias de frameworks ni librerías externas.

---

## Recursos sugeridos por el profe

- *HTML5:* Marcado semántico (<header>, <main>, <section>, <article>, <footer>), validación nativa de formularios y accesibilidad con etiquetas enlazadas.
- *CSS3:* Variables CSS en :root, Flexbox, CSS Grid, pseudoclases (:hover, :disabled) y diseño responsive adaptativo mediante Media Queries.
- *JavaScript Vanilla (ES6+):* Manipulación del DOM, delegación y captura de eventos (input, submit, click), template literals y métodos de arrays (filter, find, forEach, map).
- *Almacenamiento Local:* Persistencia en localStorage mediante serialización JSON (JSON.stringify, JSON.parse).
- *Control de Versiones:* Git bajo la metodología GitFlow simplificado (main, develop, ramas feature/* y release/*).
